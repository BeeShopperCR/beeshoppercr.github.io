Bee_ShopperCR — versión estática para GitHub Pages.

1. Subí index.html, style.css, script.js, logo.jpg y .nojekyll a la raíz de un repositorio de GitHub.
2. En Settings > Pages, seleccioná Deploy from a branch, rama main, carpeta /(root) y Save.
3. Esperá a que GitHub publique el enlace indicado en Settings > Pages.

Para probar localmente, abrí index.html con el navegador.
Para actualizar tarifas, enlaces o fechas, editá index.html y subí el cambio al repositorio.
El contador funciona mediante script.js.
ATENCIÓN: el número comercial está en el enlace de WhatsApp y es visible públicamente.
